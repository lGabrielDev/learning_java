A palavra-chave `var` foi introduzida no Java 10. O seu propósito principal é reduzir a verbosidade e a repetição de código, tornando a **declaração de variáveis locais** mais limpa.

O próprio Java consegue identificar o tipo da variável (como String, int, List<T>, etc.) através do valor atribuido, permitindo que o compilador (em tempo de compilação) atribua esse tipo.

---

### Regrinhas par usar

- Só podem ser declaradas em escopo local (dentro de methods).
- Essas variables DEVEM ser inicializadas.

---

### Regrinhas par usar

```java
public static void main(String[] args) throws Exception {
     var n1 = "a";
     var n2 = 1;
     var n3 = false;
     var n4 = new Person();
     var n5 = new Integer[40];


     ClasseGiganteComNomeGigante objeto1 = new ClasseGiganteComNomeGigante();
     var objeto1 = new ClasseGiganteComNomeGigante(); // código mais limpo
}
```
